# BackendTraingin
Backend training projects covering Databases, C# Fundamentals, OOP, Advanced C#, LINQ, EF Core, Pre-ASP.NET, MVC, and Web APIs# Backend Training Journey 

Backend training projects and practical assignments covering full-stack backend development using **C#** and **.NET Infrastructure**[cite: 1, 2].

---

##  Roadmap & Domains

### 1. Database Fundamentals
* **Duration:** 13 Sessions & 13 Assignments
* **Topics Covered:**
  * ERD (Entity Relationship Diagram) & Database Schema Design
  * SQL Commands Breakdown:
    * **DDL** (Data Definition Language)
    * **DML** (Data Manipulation Language)
    * **DQL** (Data Query Language)
    * **TCL** (Transaction Control Language)
    * **DCL** (Data Control Language)

---

### 2. C# Basics & Problem Solving
* **Topics Covered:**
  * Core Data Types, Value vs Reference Types, and Type Conversion
  * Control Flow statements (`if`, `else-if`, `switch`)
  * Loops (`for`, `while`, `do-while`, `foreach`)
  * Practical Problem Solving exercises using Console Applications

---

### 3. Object-Oriented Programming (OOP)
* **Duration:** 7 Sessions & 7 Assignments
* **Topics Covered:**
  * Pillars of OOP: Encapsulation, Inheritance, Polymorphism, Abstraction
  * Class structure, Interfaces, Abstract Classes, Structs, and Access Modifiers

---

### 4. Advanced C#
* **Duration:** 4 Sessions
* **Topics Covered:**
  * **Session 1:** Generics & Type Parameters
  * **Session 2:** Delegates, Events, and Lambda Expressions
  * **Session 3:** Collections & Data Structures (Lists, Dictionaries, Queues, Stacks)
  * **Session 4:** Code Execution Model, Threading, Synchronous vs Asynchronous Programming (`async`/`await`)

---

### 5. LINQ (Language Integrated Query)
* **Duration:** 2 Sessions
* **Topics Covered:**
  * **Session 1:** 6 LINQ Categories (Filtering, Projection, Ordering, etc.)
  * **Session 2:** 7 LINQ Categories (Grouping, Aggregation, Quantifiers, Partitioning, Element operations, Set operations, Join operations)

---

### 6. Entity Framework Core (EF Core) & ORM
* **Duration:** 5 Sessions
* **Topics Covered:**
  * **Session 1:** Database Communication, DbContext, EF Core Conventions
  * **Session 2:** Configuration Approaches (Data Annotations & Fluent API), Key Mapping, Entity Relationships (1:1, 1:N, N:M)
  * **Session 3:** Shadow Properties, Owned Types, Full CRUD Operations, Change Tracker & Performance, Data Seeding
  * **Session 4:** Loading Related Data (Eager, Lazy, Explicit), Inheritance Mapping Strategies (TPH, TPT, TPC)
  * **Session 5:** Database-First Approach (Reverse Engineering / Scaffolding), Writing Custom SQL Commands & Raw Queries

---

### 7. Pre-ASP.NET Core Fundamentals
* **Duration:** 3 Sessions
* **Topics Covered:**
  * **Session 1:** HTTP Fundamentals, Kestrel Web Server & Reverse Proxies, Environment Configurations, AppSettings & Environment Variables, Architecture Comparison (API vs MVC), and Request Processing Pipeline.
  * **Session 2:** Custom & Built-in Middleware, Static Files Handling, Routing Mechanisms.
  * **Session 3:** Controllers & Action Methods, Model Binding, Validation & ModelState, Action Results (`IActionResult`).

---

##  Real-World Capstone Projects

###  1. Gym Management System (MVC Project)
* **Duration:** 6 Hands-on Sessions
* **Details:** Complete end-to-end ASP.NET Core MVC Web Application built to manage memberships, trainers, subscriptions, and facility scheduling.

###  2. E-Commerce Platform (Web API Project)
* **Duration:** 7 Hands-on Sessions
* **Details:** Production-ready RESTful Web API built following standard architectural patterns for managing products, categories, orders, user carts, and authentication pipelines.
